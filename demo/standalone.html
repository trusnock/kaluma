The 5 PIO bugs, fixed — and you can watch it happen.

kaluma-project/kaluma is a tiny JavaScript runtime for the Raspberry Pi Pico, and a set of reported bugs in its PIO (Programmable I/O) support were making it unusable. The headline fix — PIO instruction memory & state machines

Issues #690 (SMs keep running after the program ends) and #691 (program not cleared between runs → the program offset drifts down to negative, and the part is unrecoverable without flash_nuke). The root cause is a C static in pico-sdk (_used_instruction_space) that only pio_clear_instruction_memory() resets — kaluma never called it after boot. The fix adds km_pio_cleanup() that runs on every program end.
